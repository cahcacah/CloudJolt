# CloudJolt

CloudJolt is a Distributed Edge Computing platform that enables real-time data processing and auto-scaling as-a-Service.

With CloudJolt, you get a lightweight tool that stays out of your way.

**What you get**

- CloudJolt is a Distributed Edge
- Computing platform that enables real-time
- data processing and auto-scaling as-a-Service

## Key Features

- CloudJolt is a Distributed Edge
- Computing platform that enables real-time
- data processing and auto-scaling as-a-Service

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CloudJolt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CloudJolt, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
